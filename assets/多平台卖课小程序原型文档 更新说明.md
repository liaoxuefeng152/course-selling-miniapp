# 讲师端小程序定位调整说明

## 更新时间
2024-04-10

## 更新背景

在开发过程中发现，讲师端小程序如果包含课程管理、直播创建/编辑、学员管理、订单管理等功能，会导致以下问题：
1. 小程序屏幕有限，复杂操作体验差
2. 讲师更习惯在PC端进行复杂管理操作
3. 移动端不适合批量操作和详细数据分析

## 更新内容

### 一、讲师端小程序定位调整

#### 新定位：数据查看与实时互动工具

讲师端小程序专注于轻量级、实时性强的场景：

✅ **小程序端保留功能：**

1. **数据看板首页**
   - 今日销售额、课程数、学员数、直播场次
   - 快速了解业务状况

2. **直播中控台**（核心功能）
   - 直播中实时评论互动
   - 连麦管理
   - 发放优惠券
   - 查看实时数据（观看人数、转化数）
   - 这是直播场景下的刚需，必须用手机操作

3. **消息通知页面**
   - 订单提醒
   - 学员提问
   - 直播预约提醒
   - 系统通知

4. **快速查看入口**（只读）
   - 我的课程（只读列表）
   - 我的直播（只读列表 + 进入中控台）
   - 学员列表（只读列表）
   - 订单列表（只读列表）

❌ **小程序端移除功能（移至PC端）：**

1. 课程管理（创建、编辑、上架、下架）
2. 直播创建/编辑页面
3. 学员管理（详细信息、导出、标签）
4. 订单管理（退款、发货等）
5. 财务报表（详细数据分析）

### 二、PC端功能规划

**PC端负责所有复杂管理操作：**

1. 课程管理
   - 创建课程
   - 编辑课程
   - 课程上架/下架
   - 课程详情查看

2. 直播管理
   - 创建直播
   - 编辑直播
   - 直播配置
   - 直播数据分析

3. 学员管理
   - 学员列表
   - 学员详情
   - 学习记录
   - 标签管理
   - 数据导出

4. 订单管理
   - 订单列表
   - 订单详情
   - 退款处理
   - 发货管理

5. 财务管理
   - 销售报表
   - 收益统计
   - 提现管理

### 三、设计原则

1. **小程序端**：快速查看、实时互动，操作简单，单页面完成
2. **PC端**：复杂配置、批量操作，功能完整，支持多任务并行
3. **数据同步**：小程序端和PC端数据完全打通，实时同步
4. **用户体验**：小程序端方便随时随地查看，PC端适合深度管理操作

### 四、页面调整

#### 新增页面（小程序端）

1. `/pages/instructor/notifications/index` - 消息通知页面
2. `/pages/instructor/courses-list/index` - 我的课程（只读）
3. `/pages/instructor/students-list/index` - 学员列表（只读）
4. `/pages/instructor/orders-list/index` - 订单列表（只读）

#### 删除页面（小程序端）

1. `/pages/instructor/live/edit/index` - 直播创建/编辑页面

#### 修改页面（小程序端）

1. `/pages/instructor/index/index` - 讲师工作台首页
   - 功能入口改为"快速查看入口"
   - 添加消息通知入口（带未读提示）
   - 添加PC端管理入口

2. `/pages/instructor/live/index` - 我的直播
   - 移除创建直播按钮
   - 移除编辑、删除功能
   - 只保留查看详情和进入中控台

### 五、交互逻辑调整

#### 快速查看页面

所有快速查看页面（课程、学员、订单）都是只读列表：

- 显示基本信息（标题、封面、价格、学员数等）
- 点击详情提示"请前往PC端查看"
- 不提供编辑、删除等操作

#### 消息通知页面

- 支持按类型筛选（全部、未读、订单、消息）
- 点击消息提示"请前往PC端处理"
- 支持标记已读

#### PC端管理入口

讲师首页和各列表页均提供PC端管理入口：

- 显示提示文案"课程管理、直播创建等功能请在PC端操作"
- 点击后跳转PC端管理平台（需要实现跳转逻辑）

### 六、数据流程

```
讲师创建课程
    ↓
PC端：创建课程 → 编辑内容 → 提交审核
    ↓
小程序端：课程列表显示（只读）
    ↓
学员购买课程
    ↓
小程序端：订单列表显示（只读）
    ↓
PC端：订单详情、退款处理
    ↓
讲师直播
    ↓
PC端：创建直播 → 配置参数
    ↓
小程序端：直播列表显示（只读） → 进入中控台 → 实时互动
```

## 影响范围

### 前端开发

1. 小程序端：
   - 新增4个页面（消息通知、3个快速查看页面）
   - 删除1个页面（直播编辑）
   - 修改2个页面（讲师首页、我的直播）

2. PC端：
   - 需要开发完整的课程管理、直播管理、学员管理、订单管理功能
   - 需要实现数据接口与小程序端共享

### 后端开发

1. 认证流程保持不变
2. 数据接口保持不变
3. 需要确保PC端和小程序端数据实时同步

### 用户体验

1. 讲师可以随时随地查看数据和接收通知
2. 直播时使用小程序端中控台更便捷
3. 复杂操作在PC端完成，体验更好
